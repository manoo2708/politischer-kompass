# Politischer Kompass 🧭

Ein kostenloser, interaktiver Selbsttest zur Einordnung
politischer Einstellungen.

## Über das Projekt

Der Test untersucht politische Einstellungen anhand
von 16 Aussagen auf zwei Dimensionen:

- Wirtschaftspolitik: links ↔ rechts
- Gesellschaftspolitik: liberal ↔ autoritär

Nach Abschluss wird die persönliche Position auf
einem vierfarbigen politischen Kompass dargestellt
und kurz erläutert.

## Funktionen

- 16 politische Aussagen
- Fünfstufige Zustimmungsskala
- Grafische Auswertung
- Individuelle Ergebnisbeschreibung
- Optimiert für Smartphones
- Keine Registrierung erforderlich
- Keine Speicherung persönlicher Antworten

## Methodik

Die Ergebnisse basieren auf einer vereinfachten,
transparenten Bewertungsmethode.

Der Test dient der politischen Selbstreflexion
und erhebt keinen Anspruch auf wissenschaftliche
Validierung.

## Datenschutz

Alle Berechnungen erfolgen lokal im Browser.
Es werden keine Antworten an einen Server übertragen.
